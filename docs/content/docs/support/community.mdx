# 社区与支持

## 社区渠道

墨术的官方社群渠道正在建设中，后续会在文档站、更新中心与后台配置中同步开放。

遇到使用问题或希望参与讨论，可以先通过 [GitHub 仓库](https://github.com/csyqlz/mogic-studio) 提交 Issue 或查看已有讨论。

## 赞助支持

如果墨术对你的创作有帮助，欢迎通过[赞助支持页面](/docs/support/donate)支持项目维护、模型测试和文档建设。

## 致谢

墨术脱胎于开源社区对 AI 创作工具的共同探索，感谢 Linux DO 社区、Codex / Claude Code 生态，以及 React、Next.js、Ant Design、PostgreSQL、FFmpeg、Fumadocs 等所有开源项目的建设者。

## 参与项目

- 在 GitHub 仓库点亮 Star，帮助更多人发现这个项目。
- 使用真实信息提交可复现的 Issue。
- 参与文档翻译、模型适配和小范围修复。
- 提交贡献前阅读仓库目录下的 `CONTRIBUTING.md`、`AGENTS.md` 与 `CLA.md`。
